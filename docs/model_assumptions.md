# Model assumptions

The register of every place where this project departs from directly measured
biology. If you want to know how much of a result is data and how much is us,
this is the document.

**Status: milestone W0 (data foundation).** No neural dynamics, no body, no
simulator yet. So the entries below are all about the *data layer*. §6 lists the
open decisions that must be settled before W1.

**Confidence vocabulary** (mirrors `common.data.schemas.Confidence`, so it is
machine-queryable — run `inspect_connectome.py --dataset ID gaps`):

| Level | Meaning |
|---|---|
| `MEASURED` | Directly observed in the cited experiment. |
| `PUBLISHED_ANNOTATION` | Curated classification from the literature, resting on many experiments. |
| `PREDICTED` | Computationally inferred from other data, not observed. |
| `ASSUMED` | Our modelling choice or engineering simplification. No direct biological backing. |

## 1. What is directly measured

Everything in `worm/data/normalized/`, and nothing else:

| Quantity | Source | Confidence |
|---|---|---|
| Which cells appear in the reconstructed volume | Witvliet et al. 2021, serial-section EM | `MEASURED` |
| Which cells contact which | Witvliet et al. 2021 | `MEASURED` |
| Chemical vs electrical contact | Witvliet et al. 2021 | `MEASURED` |
| Number of presynaptic active zones per contact | Witvliet et al. 2021, agreed by ≥2 of 3 annotators | `MEASURED` |

That is the entire list. Every other value in a loaded `Connectome` arrived from
somewhere else and says so.

## 2. Annotations we attach

| Parameter | Biological source | Confidence | Implementation | Simplification | Potential improvement |
|---|---|---|---|---|---|
| Cell category (neuron / muscle / glia / other) | WormAtlas cell listings, Cook et al. 2019 groupings | `PUBLISHED_ANNOTATION` | `worm/data/cells.csv`, generated by `tools/extract_annotations.py` | We collapse 61 free-text labels onto 4 enum values via an explicit table | Nothing pressing; the mapping is unambiguous for this field |
| Functional role (sensory / inter / motor) | WormAtlas + Cook et al. 2019 | `PUBLISHED_ANNOTATION` | `worm/data/annotations/sim_roles.csv` | The label→role mapping is *our* interpretation (see §2.1) | Per-cell curation against primary literature rather than a label mapping |
| Neuron class (`AVAL` → `AVA`) | Wang et al. 2024, Supp. File 2 | `PUBLISHED_ANNOTATION` | `worm/data/annotations/neuron_classes.csv` | None — read from the source column | — |
| Neurotransmitter | Wang et al. 2024, CRISPR knock-in reporter alleles | `PUBLISHED_ANNOTATION` | `worm/data/annotations/neurotransmitters.csv` | We take the source's single summary assignment per neuron; co-transmission beyond that is not captured | Parse the per-gene reporter columns to recover co-transmission; add the male table |
| Synaptic sign | **none applied** | — | deliberately absent | See §6.1 | Add Fenyves et al. 2020 as an **opt-in** overlay |

### 2.1 The label → role mapping is an interpretation

The source gives free text such as `"Layer 1 interneuron"`, `"Amphid, nociceptive"`,
`"Sublateral motor neuron; interneuron in White et al., 1986"`. Mapping those onto
`SENSORY` / `INTER` / `MOTOR` is a judgement. The full table lives in
`LABEL_MAP` in `tools/extract_annotations.py` — one line per label, reviewable in
a diff — and the script **fails** rather than guessing if upstream adds a label it
does not know.

Two deliberate choices inside it:

- **Labels that assert two roles keep both.** `"Sublateral motor neuron;
  interneuron in White et al., 1986"` becomes `(MOTOR, INTER)`. The source is
  recording a disagreement between studies, and flattening it would hide that.
- **Seven cells get `UNKNOWN` rather than a guess.** `CANL`, `CANR` (label
  `"Canal neuron"` — makes no chemical synapses, function unknown) and `MI`,
  `MCL`, `MCR`, `NSML`, `NSMR` (label `"Pharyngeal polymodal neuron"` — genuinely
  combines sensory, motor and neurosecretory function). Assigning any single role
  would be invention.

### 2.2 The neurotransmitter atlas distinguishes three things we preserve

Flattening these to a bare transmitter name would destroy real information, so
`neurotransmitters.csv` carries an `evidence` column:

| `evidence` | Source notation | Meaning |
|---|---|---|
| `reporter_expression` | plain, e.g. `Glu` | Clean reporter expression. |
| `reporter_expression_dim_variable` | leading `*` | Expression is dim and variable — present, but weaker evidence. Affects `AVG`, `AVJL/R`, `AWAL/R`, `I4`, `PHAL/R`, `ASIL/R`. |
| `uptake_not_synthesis` | `(uptake)` | The cell does **not** synthesize the transmitter; it takes it up from neighbours. `AVFL/R` (GABA), `CANL/R` and `ASIL/R` (betaine). It can still release it, but the genetics and manipulability differ. |
| `orphan_no_pathway_gene_detected` | `unknown (orphan…)` | No known transmitter pathway gene expressed. **This is a result, not a missing measurement** — 16 neurons: `AVHL/R`, `AVKL/R`, `BDUL/R`, `I6`, `PVM`, `PVQL/R`, `PVT`, `PVWL/R`, `RID`, `RMGL/R`. |

Every row also keeps `source_row`, the row number in the original spreadsheet, so
a disputed assignment can be checked in about ten seconds.

### 2.3 One alias in the neurotransmitter atlas

Wang et al. cannot reliably distinguish `DB1` from `DB3` and label those rows
`DB1/3` and `DB3/1`. We map them to `DB1` and `DB3`. **Both are assigned the same
transmitter (acetylcholine)**, so resolving the pair in a fixed order cannot
produce a wrong assignment for either cell. If a future source assigns them
differently, this alias must be revisited — it is in `_NT_CELL_ALIASES` in
`tools/extract_annotations.py`.

## 3. Engineering conventions

These are ours. None claims to be biology.

### 3.1 Gap junctions are stored once

A gap junction is undirected. Published adjacency matrices store it twice, once
per direction. We store it once, canonically oriented so `pre <= post`, and
reproduce the published form on demand via `Connectome.electrical_directed_view()`.

The reconciliation:

```
directed_entries = 2 * (stored - self_loops) + self_loops
directed_weight  = 2 *  stored_weight       - self_loop_weight
```

Note the asymmetry in the second line — a self-junction lies on the matrix
diagonal and is written once, not twice. This is why Witvliet #8's published
electrical weight is **851**, an odd number no naive doubling can produce: that
dataset has a weight-2 gap junction from `AIZR` to itself. Pinned by
`worm/tests/test_witvliet_import.py::TestElectricalConvention`.

### 3.2 Self-junctions and autapses are preserved, not cleaned away

Every one of the eight Witvliet datasets contains gap junctions from a cell to
itself (2–8 per dataset), and #7 additionally contains 11 chemical **autapses** —
a neuron synapsing onto itself. These are plausibly two processes of the same cell
contacting each other. We keep them because they are in the data; a future neural
runtime will have to decide what a self-connection *means* dynamically, and that
decision belongs in W1, not in the importer.

### 3.3 Cell-name canonicalization

| Rule | Applies to | Basis |
|---|---|---|
| `BWM-<quadrant><nn>` → `M<quadrant><nn>` | Witvliet muscle labels | Same cell, different convention (`BWM-VL01` = `MVL01`) |
| `excgl` → `exc_gl` | Witvliet excretory gland | Spelling variant |
| `VB01` → `VB1` | Leading-zero neuron indices | Applied **only** when stripping produces a known cell and the original is unknown, so `MDL01` is never touched |

Derived empirically: every cell label in all eight datasets was checked against
the canonical registry, and exactly these two patterns failed to resolve. The
test suite asserts the rules are **idempotent** and **injective** — no two distinct
source labels may collapse onto one id without an explicit alias, because that
would silently merge two cells and sum their synapse counts.

### 3.4 Synapse count is not conductance

The weight is a count of physical release sites. Treating it as proportional to
synaptic conductance is a *modelling assumption we have not yet made*. It is the
obvious first thing to try in W1, and it must be recorded as `ASSUMED` when we do.

### 3.5 Not committing raw source files

`worm/data/raw/` is git-ignored; only our derived output is committed, each with a
SHA-256 of the bytes it came from. Consequence: tests that re-parse the raw file
are marked `requires_raw` and skip on a fresh clone. Format, naming, graph and
annotation tests still run offline against the committed data.

## 4. Known gaps in the data itself

Not our simplifications — limits of what exists.

| Gap | Consequence |
|---|---|
| **Synaptic sign is not measured by anything** | Cannot build a signed network from measurement alone. §6.1. |
| **No synaptic strength in physiological units** | The count→conductance mapping will be assumed. |
| **Witvliet is head-only** | No ventral-cord motor neurons, only muscle segments 1–8. **Locomotion cannot be modelled from it.** Recorded as `Scope.HEAD`; asserted by `TestAnatomicalScope`. |
| **Extrasynaptic signalling is invisible** | Neuropeptide and monoamine signalling leaves no ultrastructural trace and is in no connectome. Ripoll-Sánchez et al. 2023 show this layer is large. |
| **No neural activity, no learned state** | The animals were fixed and dead. A connectome contains no memories and no ongoing dynamics. |
| **Per-neuron biophysics barely exists** | See §5. |
| **Individual variation is confounded with reconstruction uncertainty** | Datasets 7 and 8 differ. How much is biology and how much is tracing? The data cannot say. The `compare` command prints this caveat. |
| **`CANL` is absent from Witvliet #7 while `CANR` is present** | Reconstruction volume, not biology. Illustrates that "cell absent" ≠ "cell does not exist". |

## 5. Measured biophysics: less than you would hope

For W1, the honest inventory of what has actually been measured in *C. elegans*
neurons:

| Quantity | Measured value | Source | Note |
|---|---|---|---|
| Whole-cell capacitance | 0.5–3 pF (typically < 4 pF) | Goodman et al. 1998 | Comparable to the recording pipette's own capacitance, which makes it hard to measure |
| Input resistance | gigaohm range | Goodman et al. 1998 | Seal resistance ~15 GΩ is comparable to the cell's, so values are approximate |
| Isopotentiality | ASER is nearly isopotential | Goodman et al. 1998 | Justifies single-compartment models |
| Spiking | Absent in ASER and 42 other neurons surveyed | Goodman et al. 1998 | The basis for "graded, not spiking" |
| Ca²⁺ action potentials | Present in AWA | Liu et al. 2018 | EGL-19 CaV1 initiates, SHK-1 terminates |
| Plateau potentials | Present in RMD | reviewed in Lockery & Goodman 2009 | −70 mV rest, ~−35 mV plateau |
| Compound action potentials | Present in AVL | Jiang et al. 2022 | Ca²⁺ spike followed by K⁺ negative spike |

What has **not** been measured for the great majority of the 302 neurons: leak
conductance, resting potential, per-neuron time constants, gap-junction
conductance or rectification, synaptic conductance, and both reversal potentials.

The published whole-network models supply these as uniform constants of the right
order of magnitude, applied identically to every neuron. In that lineage
**connectivity is the only measured quantity in the model.** Any future
`docs/model_assumptions.md` entry for W1 must say so plainly.

## 6. Open decisions before W1

### 6.1 Synaptic sign — decide before writing any dynamics

No overlay is applied and none is offered by default. Options:

| Option | What it gives | Cost |
|---|---|---|
| **A. Fenyves et al. 2020, opt-in** | Sign for ~2/3 of chemical synapses, from presynaptic transmitter × postsynaptic receptor expression | Still a prediction; the other third is unknown; RNA-seq detection thresholds propagate in |
| **B. Transmitter-only heuristic** | Sign for nearly all synapses (e.g. GABA→inhibitory, ACh→excitatory) | **Wrong in principle.** The same transmitter has opposite effects depending on the postsynaptic receptor. Cheap and seductive; do not adopt silently |
| **C. Leave unsigned; fit sign** | No unsupported claim | Turns a biologically-derived model into a fitted one |
| **D. Run the experiment both ways** | Measures how much the *result* depends on the assumption | More work; arguably the most defensible |

**Recommendation: A as an opt-in overlay, plus D as standard practice.** Whatever
is chosen, `sign_confidence` is `PREDICTED` and never `MEASURED` — `validate()`
already rejects a connection claiming a measured sign.

### 6.2 Neuron model

| Option | Basis | Honest caveat |
|---|---|---|
| **A. Graded leaky integrator** (Wicks 1996 / Kunert–Shlizerman–Kutz 2014) | Matches the dominant graded physiology | Every biophysical constant is an order-of-magnitude assumption applied uniformly (C = 1 pF, G_leak = 10 pS, E_leak = −35 mV, g_gap = g_syn = 100 pS, E_exc = 0 mV, E_inh = −45 mV, β = 0.125 mV⁻¹, a_r = 1 s⁻¹, a_d = 5 s⁻¹) |
| **B. Phenomenological rate/calcium model** (Morrison & Young 2024) | Reproduces observed premotor dynamics well | State variable is GCaMP brightness, not voltage; weights are **fitted** to imaging data, weakening "biologically derived" |
| **C. Conductance-based** (Nicoletti et al. 2019) | Most faithful where it applies | Only AWC^on and RMD are characterized in this detail; extending to 300 neurons would be a very large silent assumption |

**Recommendation: A**, with every parameter in a config file so it is visibly
assumed rather than buried in code, and the known exceptions (AWA, RMD, AVL)
recorded as documented deviations rather than quietly ignored.

The candidate equations:

```
C dV_i/dt = -G_leak (V_i - E_leak)
            + Σ_j g_gap,ij (V_j - V_i)          # ohmic, bidirectional
            + Σ_j g_syn,ij s_j (E_j - V_i)      # graded chemical; E_j carries the sign
            + I_ext,i                            # sensory injection

  ds_i/dt = a_r φ(V_i) (1 - s_i) - a_d s_i       # φ sigmoid of width β
```

### 6.3 Other unresolved questions

- **Count → conductance.** Linear in synapse count? Saturating? Uniform per synapse?
- **Gap-junction rectification.** Some worm gap junctions pass current asymmetrically. Ignoring this is a simplification; the data to do better is patchy.
- **Self-connections.** What does an autapse or a self gap junction *do* in a single-compartment model? A gap junction to oneself is mathematically inert; an autapse is not.
- **Extrasynaptic signalling.** In scope at all? Ripoll-Sánchez et al. 2023 provide a usable network if so.
- **Which dataset for which experiment.** Head circuits → Witvliet #7/#8. Locomotion → a whole-animal reconstruction that is *not yet imported*.
- **What "resting state" means for a checkpoint.** There is no measured resting state to initialize from. Whatever we pick is `ASSUMED`.

## 7. Language discipline

Accurate: *biologically derived nervous-system model*, *connectome reconstructed
from a biological specimen*, *embodied connectome*, *biologically constrained
neural controller*, *closed-loop sensorimotor simulation*.

Not accurate here: *uploaded brain*, *resurrected animal*, *preserved
consciousness*, *digital organism*, *simulated mind*.

A connectome is anatomy. Anatomy is not dynamics, is not activity, is not memory,
and is not mind. Philosophical questions about what would be required to bridge
those gaps are interesting and welcome — labelled as questions.
